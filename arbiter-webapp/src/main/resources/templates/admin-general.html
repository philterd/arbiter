Arbiter URL

The base URL where this Arbiter instance is reachable. It is used in outbound notifications (such as new-user welcome emails) so links point back here. Include the scheme (http:// or https://) and the port if non-standard.

OpenSearch endpoint

Base URL of the OpenSearch cluster Arbiter connects to. Include the scheme (http:// or https://) and the port. Defaults to http://localhost:9200.

Max upload file size

Upper bound (in megabytes) on a single document submitted via the web upload form or the POST /api/v1/ingest endpoint. Larger uploads are rejected before they reach the redactor.

Default is 10 MB. Effective ceiling is the framework limit (spring.servlet.multipart.max-file-size); raise that property if you need a higher value than 100 MB.

Timezone

All timestamps shown in the UI are converted to this timezone.
