Defaults

Choose which Ollama instance and model are used by default for "Explain" (whole-document risk explanation) and "Second Opinion" (per-span review). Each is independent.

Security requirement: When a reviewer requests an explanation or second opinion, Arbiter sends the full unredacted document text and all PII span values to the configured Ollama instance. Ollama must be deployed with request-body logging disabled. If Ollama's HTTP server logs request bodies (e.g. when OLLAMA_DEBUG=1 is set), unredacted PII will appear in Ollama's logs outside Arbiter's security boundary. Ensure OLLAMA_DEBUG=0 and that your Ollama deployment does not forward request bodies to any external logging or observability sink. Each LLM call is recorded in Arbiter's audit log under the DOCUMENT_PII_SENT_TO_LLM action.
